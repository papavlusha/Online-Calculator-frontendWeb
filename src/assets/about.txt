Добро пожаловать в Online Calculator!

О проекте:
Наш проект представляет собой многофункциональный онлайн-калькулятор, разработанный для решения различных математических задач. Приложение поддерживает несколько языков интерфейса (белорусский, русский и английский) и предоставляет возможность выбора между реализациями на C++ и Java.

Основные возможности:
- Матричные вычисления
- Конвертация чисел между системами счисления
- Чат для общения пользователей
- Вычисление простых чисел
- Базовые математические операции

Наша команда:
Мы - группа энтузиастов-разработчиков, стремящихся создать удобный и функциональный инструмент для математических вычислений. Наша цель - сделать сложные математические операции доступными и понятными для каждого пользователя.

Технологии:
Проект разработан с использованием современного стека технологий:
- Angular для frontend-части
- Поддержка многоязычности через ngx-translate
- Реализация вычислительного ядра на C++ и Java
- Responsive design для удобства использования на различных устройствах

Мы постоянно работаем над улучшением функционала и будем рады вашим отзывам и предложениям по развитию проекта.

Спасибо, что выбрали наш калькулятор!
